# LOTM Pathway Encounters — Spaced List

## Proyecto MCP

- Universo: `LOTM | What You Will Find in Each Pathway | Spaced List`.
- Variante de: `LOTM | What You Will Find in Each Pathway`.
- Estructura: 3 secciones, 25 slides en total.
- Contenido: 3 portadas y 22 cartas `Pathway List`.
- Arte: se reutilizan las 25 referencias de imagen del proyecto base; no se
  duplican binarios.
- Copy: el texto aprobado se conserva; solo cambia su presentación de párrafo
  a lista numerada con más aire.

## Orden de las secciones

### 01 — You Picked the Weird One

Portada + Wheel of Fortune, Abyss, White Tower, Demoness, Door, Mother y
Error.

### 02 — The Build Gets Worse

Portada + Sun, Chained, Fool, Paragon, Death, Visionary, Black Emperor y
Moon.

### 03 — Now It Is Personal

Portada + Tyrant, Hermit, Red Priest, Darkness, Justiciar, Hanged Man y
Twilight Giant.

## Nota de producción

Las portadas mantienen su composición propia. Cada pathway usa el fondo, el
color y la escala tipográfica que ya tenía en el proyecto base. La diferencia
visible es el nuevo tipo [[Pathway List Card]]: título compacto, lista real,
índices automáticos y separación entre entradas.
